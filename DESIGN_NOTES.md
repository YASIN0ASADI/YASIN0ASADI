# Design notes

The README introduction is unchanged. The monochrome banner uses local SVG/SMIL animation without JavaScript or a hosted banner API. Network tunneling is intentionally described without an invented project name.

Avatar: generated using the built-in image generation tool; the original PNG is retained and a smaller JPEG export is included for profile-picture upload.

## Avatar prompt

Use case: logo-brand. Asset type: square GitHub profile avatar for the nickname Invincible. Create one finished premium monochrome emblem, centered and highly legible at 48px. A bold original abstract capital I monogram with crisp opposing bracket-like angular cuts and a subtle sense of forward movement. Restrained cyber/network identity, sophisticated editorial minimalism. Pure black background with a barely visible graphite radial vignette. The mark is white with very subtle grayscale beveled edge depth, sharp clean contours, strong silhouette. Center the whole emblem in the middle 60 percent of the square so a circular avatar crop will not clip it. Black, white, and neutral grays only. No words, no small lettering, no extra badges, no watermark, no people, no hood, no skull, no mask, no shield, no lock, no globe, no Matrix rain. Deliver a square image.
